# 官方 Hermes Desktop 功能差距：按实现难度整理

日期：2026-10-30。本文对照[官方 Hermes Desktop 用户文档](https://hermes-agent.nousresearch.com/docs/user-guide/desktop)与本仓库当前 `feature/v0.1.8` 工作树，整理尚未对齐或只完成一部分的**产品入口**。产品运行时锁定的 Hermes fork 为 `882037eb8745b505db438217513c4c94f95c93c1`，官方基线为 `v0.22.5`；官网持续更新，官网当前能力不等于该锁定提交或本客户端已有能力。版本、实现与验收以 [`ROADMAP.md`](../ROADMAP.md)、[`docs/capability-matrix.md`](capability-matrix.md) 和当前代码为准。

这是需求梳理与相对难度判断，不是已批准的开发范围、工期估算或验收结论。难度假定优先复用锁定 Gateway，在产品前端、契约及桌面适配层实现；如果需要改 Hermes fork，须另按仓库审批与独立 PR 流程处理。Windows 与 macOS 均须分别设计和验收。当前工作树还有其他未提交开发，尤其 `/journey` 学习时间线已在开发分支接入、原生操作尚待验收；不能仅凭下表的快照判断后续交付状态。

## 已有基础

客户端已经有流式聊天、会话历史及切换、Profile、模型设置、Skill/MCP 与 Agent 插件、定时任务、飞书/微信扫码、工作区文件与终端、局部文件/图片预览和全局快捷输入。`/agents` 可查询当前会话子代理快照，部分会话命令在开发分支接入。上述能力在各平台的原生操作、真实模型和安装包上的验证范围不同，不把代码存在视为已验收。

## 差距清单：从容易到困难

| 难度 | 功能 | 当前基础 | 待补齐的用户能力及主要工作 |
| --- | --- | --- | --- |
| ① 较容易 | 子代理任务列表 | `/agents` 调用当前会话的 `subagent.list`，文字显示快照 | 聊天中显示任务、状态、空态与读取错误；按 Profile/会话隔离，不能把普通会话当子代理。 |
| ① 较容易 | 子代理详情 | 锁定 Gateway 有 `subagent.tail` | 展示选定子代理近期活动和输出，处理任务结束或会话切换。 |
| ① 较容易 | 按键语音听写 | 锁定 Gateway 有 `/api/audio/transcribe`；产品尚无录音入口 | 麦克风录音，转写文字进入输入框，由用户确认发送；固定录音开始时的 Profile/会话。 |
| ① 较容易 | 助手回复朗读 | 锁定 Gateway 有 `/api/audio/speak`；产品尚无播放入口 | 合成并播放回复，提供开关和停止；切换会话时停止旧音频。 |
| ① 较容易 | 其他消息渠道的配置入口 | 飞书和微信可扫码，其他渠道主要只读 | 按实际渠道逐项增加配置、连接测试、保存结果与重启反馈；不能把状态展示算作接入。 |
| ② 中等 | 子代理引导与停止 | 锁定 Gateway 有 `subagent.steer`、`subagent.interrupt`，产品尚未开放 | 增加会话归属校验、确认回执和最终状态显示；`queued` 只表示引导已排队，`found` 不等于子代理已经结束。 |
| ② 中等 | 子代理实时进度 | 产品事件白名单未转发 `subagent.*` | 接收启动、进度、完成事件；进入会话及重连后用快照校正，避免永久显示运行中。 |
| ② 中等 | 会话标签 | 已能切换多个会话，右侧标签用于文件/终端 | 同时保留多个打开的聊天，以及各自草稿、附件与滚动状态。 |
| ② 中等 | 产物画廊 | 有局部文件、图片预览 | 从会话结果归集文件、图片和链接，支持检索、来源会话回跳及预览。 |
| ② 中等 | 命令面板 | 聊天输入有 `/` 候选 | 跨页面搜索会话、操作和设置，并保留快捷导航。 |
| ② 中等 | 可配置快捷键 | 有全局快捷输入及其快捷键 | 更多应用操作的绑定、冲突检查、保存与恢复。 |
| ③ 较难 | 多窗口会话 | 一个主窗口及独立快捷输入窗 | 弹出聊天窗口，同一会话多窗口状态同步，处理关闭、托盘和进程生命周期。 |
| ③ 较难 | Git 差异审查 | 工作区可浏览文件、使用终端 | Git 状态、变更列表、差异及来源范围；先保证只读视图准确。 |
| ③ 较难 | Git 写操作与 worktree | `/worktree` 当前禁用 | 暂存、提交、分支及隔离工作树创建/清理，明确目标仓库和未提交改动边界。 |
| ③ 较难 | 网页与工具结果预览 | 有本地文件预览 | 内置网页/HTML 与工具结果预览，保持页面状态并关联所属会话。 |
| ③ 较难 | 远程 Gateway | 当前管理产品自有本地 Gateway | 连接保存、鉴权、测试、切换与断线恢复，明确远端 Profile、会话、文件和凭据归属。 |
| ③ 较难 | `chained` 连续语音 | 锁定 Gateway 有 STT/TTS 接口 | 串起转写、Hermes 回合、合成与下一轮监听；处理静音检测、打断、取消和状态恢复。STT、语音回合模型与 TTS 可分别配置。 |
| ③ 较难 | 首次启动引导 | 已有分散的设置页 | 分步完成模型、权限、渠道与首条消息，允许跳过及重新进入。 |
| ④ 很难 | Bot 固定聊天与 Bot 间移交 | 有独立 Profile，`/handoff` 尚未接入 | Bot 身份、固定会话、目标解析、跨 Bot 路由及失败恢复。 |
| ④ 很难 | Bot 群聊 | 尚无产品入口 | 多 Bot 发言规则、并发、历史与错误处理。 |
| ④ 很难 | 可保存的多面板布局 | 有侧栏与右侧工作区 | 布局编辑、面板位置和尺寸持久化，以及多窗口状态。 |
| ④ 很难 | 页面元素批注 | 尚无内置网页交互预览 | 在网页上选取元素、截图、保存批注，再由用户确认加入聊天。 |
| ④ 很难 | `gpt-live` 全双工语音 | 锁定 Gateway 有 Live 会话创建接口，产品无 WebRTC 链路 | WebRTC、实时事件、委派到 Hermes 会话、音频打断与断线清理。可配置 Live 模型、语音、密钥及地址，但端点必须兼容现有 `/live/sessions`、WebRTC 与委派事件协议。 |
| ④ 很难 | Webapp 与其他设备访问 | 产品没有相应入口 | 浏览器工作台、远程鉴权、会话共享和文件访问边界。 |
| ⑤ 架构级 | Desktop Plugin SDK | 已管理 Hermes **Agent** 插件 | 允许桌面插件扩展页面、面板、命令、快捷键和主题，并定义加载、卸载与权限边界。 |
| ⑤ 架构级 | 任意自定义全双工语音服务 | `gpt-live` 支持自定义 `base_url`，但使用固定 Live 协议 | 不兼容该协议的服务须单独开发实时音频、事件与委派适配，不能仅替换 URL。 |

## 单独决策的能力

- **文件 `/rollback`**：当前禁用；`/undo` 只回退会话消息，不恢复文件。锁定 Gateway 的安全恢复存在手工修改被覆盖的边界，见[接口提案](desktop-remaining-slash-commands-gateway-boundary.md)。不能按“容易实现”直接开放。
- **Profile 导入/导出、唤醒词、HUD 浮窗与桌面宠物**：均需要独立产品范围和验收条件。`/journey` 学习时间线已在当前开发分支接入，Windows/macOS 原生操作尚待验收；不再列为未接入功能。
- **`/bg` 完整任务管理**：开发分支已有提交与结果展示，单任务查询、取消、实时进度及 Gateway 重启后终态恢复仍缺接口；见同一份[接口提案](desktop-remaining-slash-commands-gateway-boundary.md)。

## 建议实施顺序与验收门槛

先验收现有核心功能的 Windows/macOS 原生窗口与真实模型路径，再考虑新功能。按投入和可见收益，首批候选为：子代理可见列表与详情、按键听写、回复朗读、会话标签、产物画廊。随后考虑子代理控制与连续语音。远程 Gateway、Bot 协作、Desktop Plugin SDK 分别立项，避免在一个版本里同时改变连接、会话和插件边界。

每项实施前须核对锁定 Gateway 的生产请求、授权、参数及返回值；两端共享逻辑放在公共层，Windows/macOS 麦克风、窗口、通知和进程行为分别留在适配层。至少记录开始、关键状态、完成或失败及清理结果；不得记录密钥、音频内容或敏感路径。实现后记录代码检查、真实 Gateway 接受/拒绝结果、双平台原生操作与未验收范围。本文的难度等级不替代这些验证。

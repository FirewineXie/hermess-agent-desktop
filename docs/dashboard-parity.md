# Hermes Dashboard 桌面功能对照

基线：产品锁定的 Hermes fork `882037eb8745b505db438217513c4c94f95c93c1`。范围以该提交的 `web/src/App.tsx` 内建路由及 Kanban 插件 API 为准。Hermess 页面由产品 React 实现，经共享契约和桌面 Rust 适配调用锁定 Gateway；不装载上游静态页面。本表只记录已核对的入口覆盖情况，**页面存在不等于操作一比一完成**。

## 范围与当前结论

“Dashboard 一比一”只要求覆盖锁定版本已经存在的页面、控件、状态、成功/拒绝/失败反馈及接收方协议。锁定 Dashboard 是当前功能范围的唯一基线；锁定版本没有提供的增强能力暂不实现，也不阻塞一比一验收。反过来，自动测试或页面存在不能替代本表要求的原生窗口与真实接收方验证。

锁定 Kanban Dashboard 已经提供的多 Profile 编排和任务工作区能力属于必做范围，不能误归为后续增强：

- 编排 Profile、默认负责人、`auto_decompose` 自动拆解和 `auto_promote_children` 自动推进；
- 手工拆解任务、父子任务依赖、Dispatcher 分派、Worker 运行和子任务成果展示；
- `scratch`、Git Worktree 和指定目录三种任务工作区；
- `review` 状态、审核负责人及锁定工作流允许的审核流转。

当前明确不实现的 Dashboard 外能力只有：

- 单任务浏览器、MCP、终端或桌面软件的允许/禁止权限；任务仍按锁定行为指定 Skill，并继承负责人 Profile 的有效工具集；
- Cron 自动创建 Kanban 任务、比较前后结果并仅在变化时通知的一体化流程；
- 超出锁定 Dashboard 的逐文件代码 Diff 审阅、选择性接受及确认应用到主工作区的流程；Git Worktree 和普通 `review` 流转仍属于必做范围；
- 保存 Worker 执行现场并从原进度继续的可恢复暂停；终止、回收和重新调度仍按锁定 Dashboard 实现；
- 旧路径、旧任务收据或旧数据格式兼容。

当前阶段再收敛三项交付口径：

- 系统维护暂缓，不作为本轮继续开发或验收的阻塞项；已有实现保留，但不据此宣称完成原生实机验收；
- MCP 只实现与服务商无关的通用配置和管理页面，覆盖任意 HTTP/stdio 服务、通用认证、参数、环境变量、启停、删除和连接测试；不为 GitHub、Notion 等具体服务商新增专属页面；
- 渠道保留当前实现和已完成的协议验证，真实扫码、桥接及消息收发由用户后续自行测试，不作为本轮代理验收项。

除上述暂缓或移交测试的范围外，当前反向审计未发现基线之外需要追加的客户端功能；其余剩余工作是锁定能力的 Windows 真实写操作、真实模型与外部服务、macOS 和安装包验收。

产品范围明确排除 Nous Portal 的账户、订阅与权益状态：Rust 在模型 OAuth 的投影与操作边界过滤 `nous`，第三方 Dashboard 插件代理同样过滤列表并拒绝 Nous OAuth 路径及编码绕过，既有白名单拒绝 `/api/portal`；Profile 工具集页面过滤需要 Nous 账户或托管权益的提供方。Nous 模型提供商卡片仍作为模型接入能力保留。其余模型 OAuth 保留各模型提供商的登录、状态与断开能力。当前 Profile 的人格与记忆页则补齐锁定 System 页的内置记忆重置，可分别删除 `MEMORY.md`、`USER.md` 或两者，并在成功后回读磁盘状态。

非路由级的主题与字体能力适配为本设备全局外观偏好，不写入 Profile 的 `dashboard.*`：支持跟随系统、浅色、深色及系统无衬线/衬线/等宽字体。System 页的 Hermes Console 由产品 React/xterm 与 Rust WebSocket 代理实现，WebView 不接触 Gateway 凭据，也不启动 Shell、PTY 或新进程。外部记忆提供方除配置、OAuth 与激活外，依赖安装也由产品共享进程管理器执行锁定 helper，不直接调用会自行启动子进程的 Dashboard setup 路由。

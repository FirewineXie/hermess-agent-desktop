# Hermess Agent Desktop v0.1.9

## 新增功能

- 以桌面页面接入会话、文件、模型、渠道、定时任务、扩展、Profile、密钥和运行时管理，并提供多 Profile 持续任务看板。
- 聊天支持附件、产物预览、子代理面板、多会话标签、独立窗口、全局命令面板，以及 Bot 单聊和多人群聊。
- 新增首次启动引导；设置页支持按 Profile 管理模型、OAuth、记忆、凭据和环境密钥，并提供产品数据备份。
- 自定义模型提供商同步到其他 Profile 时，可一并复制已配置的 API Key；桌面端支持连接和切换远程 Gateway。

## 修复问题

- 优化侧栏和设置导航，整理会话管理页的统计、筛选、列表滚动和重复标题。
- 修复群聊中的内部事件展示、输入法选词误发送和 Bot 失败详情显示问题。
- 修复多 Profile 操作可能落入错误 Profile，以及持续任务审核人和执行者相同的问题。
- 统一记忆与上下文设置中的压缩模型操作按钮样式。

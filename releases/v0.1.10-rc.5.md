# Hermess Agent Desktop v0.1.10-rc.5

## 新增功能

- 新增独立 Code 编程视图，支持项目管理、多模型提供商、从 Profile 同步静态密钥连接，以及编程会话保存、恢复、归档和删除。
- 编程运行时按需下载，编程配置、凭据和历史独立存储；支持图片粘贴、拖入及本地文件引用。
- 编程聊天支持工具过程、文件变更、审批选项、运行耗时、Git 分支和上下文用量展示。
- 接通原生 `/goal`、`/plan`、`/compact` 和 `/review`，支持持续目标状态与编辑、计划澄清、上下文压缩和代码审查。
- 编程设置支持直接编辑 `config.toml`，配置 MCP、Skills、项目指令、上下文及自定义权限。
- Windows 电脑操作增加状态提示和停止接管入口，关联编程任务及本地 Gateway 已订阅会话。
- 设置新增会话分类，支持配置自动归档和查看已归档聊天。
- Windows 全新安装首次启动时准备默认工具及依赖，并在失败后支持重试。

## 修复问题

- 修复 Chat/Code 主视图切换、编程目录选择和侧栏会话按钮布局，保留会话、草稿及项目归属。
- 修复已有编程运行时仍显示下载失败的问题，重试时复用有效安装并清除旧失败状态。
- 飞书、微信扫码取得授权后立即隐藏二维码，保存失败保留错误与重试入口。
- 托盘退出时清理产品管理的插件本地服务，首批覆盖 OpenViking Quick Local。
- 收紧聊天正文和工具间距，补齐编程设置与弹窗深色样式，修复浅色页面原生控件误用深色配色。

# Hermess Agent Desktop v0.1.9-rc.4

## 新增功能

- “新建会话”可选择单独聊天或多人群聊；群聊在主聊天区打开，历史可从侧栏继续访问。
- 侧栏将群聊与专家会话历史放在主要滚动区域，其他功能收纳到下方“功能”菜单。

## 修复问题

- 群聊隐藏内部成功事件与事件序号，仅展示对话及需要处理的状态；Bot 回复失败时显示失败类别和可展开的错误详情。
- 群聊输入框支持 Enter 发送、Shift+Enter 换行，避免中文输入法选词时误发送。
- 修复专家管理详情页中较长名称被操作按钮挤压、逐字换行的问题。

## Hermes fork 版本

- 基于 Hermes Agent v0.22.5；fork hermess-desktop（882037eb8745b505db438217513c4c94f95c93c1）。

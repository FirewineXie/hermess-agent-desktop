# Hermess Agent Desktop v0.1.7

本版本从已合入 `main` 的提交构建。正式发布任务须先通过该提交的必需检查，再分别构建并核对 Windows x64 与 macOS Apple Silicon 安装包；实际可下载附件及 SHA-256 值以本 Release 为准。macOS Intel 与 Linux x64 不在本次默认发布范围内。

## 本版本内容

- Windows 运行时使用程序目录下固定的 `runtime/payload` 路径。覆盖安装先准备并校验新运行时，再切换目录；新 Gateway 启动成功后，客户端后台清理带本产品标记的旧目录。用户 Profile 与依赖环境仍保存在本产品的数据目录。
- 修复安装器读取运行时摘要后可能留下文件句柄、误报旧运行时被占用的问题。短暂占用时可重试；切换失败后再次运行可复用完整的暂存目录。
- 桌面端通过自有 Gateway 的私有控制端发现进程并获取交互票据，修复 Windows 长路径下的控制管道定位。发行版辅助 Python 使用随包基础解释器，并在打包前检查运行时搬迁后的导入能力。
- 改进模型提供商配置、默认模型编辑、Profile 配置查看与编辑，以及相关桌面页面体验。
- 调整发行流程：开发源码保持统一的 `0.0.0` 版本，发布构建在临时检出目录写入本 tag 的版本；正式 tag 在两个默认平台的附件及校验清单准备成功后创建。

## 验证与限制

- Windows 本地已通过前端构建、架构与契约检查、Rust 格式检查及单元测试。离线安装包构建和隔离安装器测试通过；在现有安装目录完成静默覆盖安装，并核对固定运行时路径与暂存目录切换。具体测试记录见 `ROADMAP.md`。
- 交互安装界面、新 Gateway 启动后的后台清理、真实模型调用及 macOS 原生安装仍待实机验收。GitHub Actions 构建成功只证明对应安装包已构建并汇总，不代表这些场景已验收。
- Windows 安装包尚未签名；macOS 使用临时签名，尚未进行 Apple Developer 签名和公证。

下载适用于当前平台的附件，并使用同一 Release 的 `SHA256SUMS.txt` 核对文件。

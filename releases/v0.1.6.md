# v0.1.6 版本说明

本版围绕桌面页面、Profile 隔离和本地使用流程更新。本文记录 `feature/v0.1.6` 当前已实现的内容；正式版 tag 和 GitHub Release 尚未发布，安装包与原生操作的验收状态以下方说明为准。

## 本版本内容

- 重构 Profile 概览、新会话、工作区、能力目录和定时任务页面，整理顶部导航、侧栏及 Windows 自定义标题栏。侧栏按 Profile 展示最近会话，支持分批展开；新会话输入区和窗口布局随可用空间调整。
- 聊天、模型、Agent 配置、个人文件、扩展、渠道、统计及工作区操作显式指定目标 Profile。切换查看时分别保留已访问 Profile 的界面状态，Gateway 事件和审批按已确认的会话归属处理。单 Profile Gateway 的服务状态识别也已修正。
- 专家目录提供内置预设与自定义 Profile 创建入口；Skill、MCP 安装可选择目标 Profile。「专家管理」集中展示当前 Profile 的技能、MCP、工具集配置和数据目录，其中数据目录可在页面内逐级浏览。
- 定时任务按已服务的 Profile 汇总和搜索，支持创建、编辑、暂停、恢复与立即运行。列表、详情和编辑使用锁定 Hermes 的私有 Dashboard 接口；立即运行由客户端向该接口后台发起请求，界面提示“已发起”不代表任务执行成功。
- 提供 `pnpm deps`、`pnpm start` 和按系统打包的 `pnpm pack:win`、`pnpm pack:mac`、`pnpm pack:linux` 命令。Windows 新安装的 NSIS 默认目录名改为 `HermessAgentDesktop`；运行时诊断入口默认收起，按页面键盘序列显示 Debug 开关。
- 顶栏 GitHub 图标通过桌面宿主调用系统默认浏览器打开项目仓库。更新入口按所选通道、本机资源和当前版本判断是否显示新包提示。

## 验证范围与限制

- Windows 本地已多次通过前端类型检查、桌面 UI 构建、架构与契约检查、Rust 格式/编译及相关单测；Profile 切换、部分页面布局和数据目录浏览已在开发态原生窗口核对。各项验证对应当时的源码状态，不能视为本版安装包的完整验收。
- `0.1.6` 的 Windows NSIS 安装包曾在本地构建成功，但安装向导、实际安装、升级及卸载尚未验收。后续代码提交后的安装包结果需重新核对。
- 双 Profile 并发写入、审批、扫码与真实消息收发、定时任务真实模型执行、Skill/MCP 安装，以及 macOS 和 Linux 的原生窗口与安装流程仍待验收。命名 Profile 的 Agent 工具目录读取受锁定 Hermes fork 的现有路由限制。
- 正式发布前仍需按 `docs/release-process.md` 核对版本、上游锁定提交、发行资源、PR 检查和实机结果。GitHub Release 附件以届时 tag 工作流结果为准。

完整进度与逐项限制见 `ROADMAP.md`、`docs/capability-matrix.md` 和 `docs/profile-switch-transition-optimization.md`。

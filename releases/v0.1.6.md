# Hermess Agent Desktop v0.1.6

首个正式版本。发布工作流为 Windows x64 和 macOS Apple Silicon 构建离线安装包；实际可下载平台以本 Release 的附件为准。安装包包含锁定版本的 Hermes Agent 运行时；首次启动时由桌面客户端在自己的数据目录中准备运行环境。Linux 安装包本次暂不提供。

**同版本重新发行**：此前 `v0.1.6` 的 Windows 附件由本机手动构建并上传。本次删除该 Release 和旧 tag 后，从更新的 `main` 提交重新创建同名 tag，由 GitHub Actions 重新构建并发布。重新下载时请以本 Release 最新的 `SHA256SUMS.txt` 核对安装包；此前下载的同版本文件不应沿用旧校验值。

## 功能

- **聊天与会话**：中文桌面聊天界面，流式回复、Markdown 展示、思考过程和工具执行状态；可查看与恢复历史会话、停止当前回复，并处理工具审批与澄清。支持文件及图片附件、原生文件选择和拖入。输入 `/` 可查找可用命令，输入 `@` 可选择当前会话的 Skill。
- **多专家 Profile**：内置专家预设和自定义 Profile。聊天、模型、Agent 设置、个人文件、扩展、渠道、统计及工作区操作按所选 Profile 访问；侧栏按 Profile 展示最近会话，切换查看时保留各自已加载的界面状态。「专家管理」集中查看技能、MCP、工具集配置和数据目录，并可逐级浏览 Profile 文件。
- **模型与 Agent 配置**：配置模型提供方、接口地址、密钥、模型列表和思考强度；支持命名提供方的模型发现并把新模型追加到本机列表。可管理 Agent 设置、人格与记忆文件。
- **工作区**：保存常用本地文件夹，在指定目录中新建会话；恢复会话时沿用其工作目录。工作区页面提供文件浏览和终端操作入口。
- **扩展与工具**：浏览和安装 Skill、MCP，并选择目标 Profile；查看与管理已配置的 MCP。工具页区分随包资源、可下载工具与系统命令，支持检查和按需安装可用工具；新安装的工具需要重启自有 Gateway 后才会进入其 PATH。
- **定时任务**：按已服务的 Profile 查看和搜索任务，支持创建、编辑、暂停、恢复与立即运行，并展示计划和最近执行状态。点击“立即运行”仅表示请求已发出，执行结果应以任务状态为准。
- **渠道接入**：提供飞书和微信扫码接入界面，使用桌面客户端管理的 Hermes Gateway 承载聊天和消息渠道。
- **桌面体验与运行时**：重做 Profile 概览、新会话、工作区、能力目录及定时任务页面；Windows 自定义标题栏、系统托盘与单实例窗口。客户端使用独立的数据根和自有 Gateway 进程，与其他 Hermes 安装隔离；提供运行时诊断和页面缓存清理设置。
- **版本与更新**：「关于」页展示产品、上游版本、许可证和工具来源；更新页可选择正式版或 RC 通道，并在可访问的发行源中检查及下载适用安装包。下载后仍需手动运行安装程序。

## 安装与升级

下载与系统匹配的附件，核对 `SHA256SUMS.txt` 后运行。已有 0.1.5 的用户可运行 0.1.6 安装程序做覆盖安装。本次包尚未完成从 0.1.5 覆盖安装、卸载和真实模型的完整实机验收；升级前请自行保留重要数据副本。

Windows 安装包目前未做代码签名；macOS 暂采用临时签名，未完成 Apple Developer 签名与公证。GitHub 仓库现已公开，外部用户可直接下载本 Release；客户端可匿名检查更新并下载适用安装包，安装仍需手动完成。

## 构建与验证

本次附件由 `v0.1.6` tag 对应的 GitHub Actions 工作流构建；工作流核对四处产品版本、锁定的 Hermes fork 提交、许可证和离线载荷，并为附件生成 SHA-256 清单。CI 构建成功不等于原生安装、覆盖升级、卸载、真实模型或跨平台实机验收。

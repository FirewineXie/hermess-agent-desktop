# Hermess Agent Desktop v0.1.11

## 新增功能

- 聊天内可确认或跳过目录插件、Skill 和 MCP 的安装或连接请求，返回会话可恢复待确认卡片。聊天也会显示工具进度与风险提示、待办、MoA 进度和子代理活动。
- 顶部 Gateway 菜单可切换本机与已保存的远程 Gateway，显示各 Gateway 的未读通知。终端可按主机独立打开。
- 运行时设置增加 Web Access，可通过 HTTPS 使用 Gateway 的浏览器界面，并可生成或导入证书。
- 定时任务支持时区、错过后补跑、停止本次运行和投递到群聊。群聊支持共享笔记、主 Bot 和继续讨论。
- Profile 支持锁定 Skill、批量更新 Hermes 插件、迁移 Vault 密钥及从其他 Agent 导入数据。魔搭 MCP 条目可打开所选 Profile 的配置表单。
- 会话支持编辑重发、从历史消息分叉、刷新提示词和恢复 Profile 默认模型。Kanban 支持固定看板快捷标签。
- Profile 插件管理页显示 Dashboard 插件声明的页面与插槽、实际注册结果及加载失败原因。独立插件页可切换 Profile，并在插件不可用时提供安装和管理入口。
- 内置 `hermess-plugin-development` Skill，可在聊天中按需求开发 Dashboard 插件，随客户端部署到本地 Profile。
- 「设置 → 模型 → 辅助模型」集中管理内置辅助模型和默认委派的子 Agent 模型。
- 新会话默认工作区改为按 Agent 保存；工作区快捷列表仍由所有 Agent 共用，并可将同一目录分配给多个 Agent。

## 修复问题

- 修复群聊切换到 Code 时两种页面同时显示的问题，以及设置分类溢出后无法滚动的问题。
- 修复部分聊天历史操作、远程 Gateway 配置入口、深色主题和终端空态的显示问题。
- MCP 授权失效时提示重新授权，运行中的聊天可从输入框排队或使用 `/steer` 插入指令。
- 修复从 Git 安装插件后误报未启用、回退模型配置因字段顺序不同而误报回读失败的问题。
- 优化聊天中的审批、建议、后台任务、子代理任务和完成通知展示，并修复待发送图片附件无法移除的问题。
- 修复安装版终端已经输出内容但文字与深色背景过于接近、看起来近似空白的问题。
- 修复飞书、微信等外部渠道触发聊天后，客户端缺少用户原始消息的问题。
- 修复飞书、微信扫码接入被固定为直接放行的问题；现在可选择新发信人需要审批或直接放行，选择后自动检查登录结果。
- 修复备份遇到修改时间早于 1980 年的文件时跳过文件并生成不完整归档的问题；文件内容现在会正常写入 ZIP，且不修改源文件时间。

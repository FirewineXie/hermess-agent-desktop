# v0.1.0 内测构建

首个跨平台 GitHub Actions 构建候选。此版本用于验证固定 Hermes Agent 提交与独立 Tauri 桌面端的打包边界，尚未达到正式发布验收标准。

## 本版本内容

- 固定上游 Hermes Agent 提交 `5894e750c3dba980d43b25aa29e3958149ba2c61`，产品代码与上游源码分离。
- 中文桌面界面支持模型设置、会话创建与历史恢复、流式回复、停止、审批、澄清、文件和图片附件。
- 运行时归档随安装包交付，首次启动解包到所选主要存储位置，并核对摘要和上游版本。
- Windows 构建 NSIS；macOS Intel/Apple Silicon 构建 DMG；Linux x64 构建 AppImage 和 deb。

## 已验证与限制

- Windows x64：固定核心包的假模型协议冒烟、离线归档解包，以及同机 NSIS 静默安装和卸载已通过。
- macOS 与 Linux：本标签的 GitHub Actions 构建结果用于建立基线；原生窗口、安装、真实模型和工具链验收仍需在对应系统完成。
- 安装包未配置正式代码签名与 Apple 公证。请勿将此版本视为已通过三平台正式发行门槛。
- 本仓库自行编写的代码采用 PolyForm Noncommercial 1.0.0；上游 Hermes Agent 子模块保留其 MIT 许可。

完整实施状态见 `docs/I0-implementation.md` 和 `docs/capability-matrix.md`。

# Hermess Agent Desktop v0.1.8-rc.2

这是 v0.1.8 的第二个候选版本，包含 rc.1 的功能及以下增量。tag 推送后，发布工作流分别构建 Windows x64 与 macOS Apple Silicon 安装包；两个默认目标均成功后才创建预发布 Release，可下载附件以实际构建结果为准。

## 本次新增与修复

- 统一设置新增安全三页及高级五页：审批与允许列表、隐私与共享指标同意、检查点配置与只读清单，以及运行参数、工具、终端、输出限制、完整 Schema/YAML。删除旧独立 Agent 配置页和 Profile 内嵌编辑状态；保存后回读核对，对象准确替换，YAML 有校验和提交前外部修改检查。
- 新增结构化模型/Profile 委派路由，支持密钥保留、替换、清除，有序回退与 JSON 请求覆盖。自定义提供商仅同步到不存在同 ID、名称或地址的目标，不覆盖已有提供商、不复制凭据、不改变目标主模型。
- 新增设备级保持唤醒、Windows F12 与全局快捷输入窗口；快捷输入绑定 Profile/会话，走原聊天发送链路，防止重复提交，并在退出时清理资源。
- 通知补齐后台任务、其他会话结束、额度及插件消息，提供七类独立开关，接入真实运行时事件、去重和原会话点击定位。
- 新增聊天截图粘贴与附件缩略图；侧栏展示运行、待审批、待补充信息、完成及失败状态，修正思考预览结束时过早报告完成的问题。
- 新建 Profile 不继承原 Profile 的主模型及自定义提供商；补充上述功能的契约、测试与迁移文档。

## 已执行验证

Windows 本地前端类型检查、桌面生产构建、架构/契约/生成契约、Rust 格式、许可证与锁定上游检查通过。当前全量前端测试 59 项通过，Rust 测试 100 项通过、5 项按环境忽略；另完成隔离运行时配置测试、相关上游定向测试及假模型 Gateway 冒烟。PREVIEW_ONLY 页面验证了配置、同步、委派、快捷输入和扩展通知的相关交互。本地原生开发客户端已运行并取得 backend_ready。

这些结果不等于安装包、真实服务或双平台原生验收。详细记录见 ROADMAP.md 及 docs/settings-models-desktop-capabilities.md、docs/settings-security-advanced.md、docs/settings-notification-events.md。

## 尚未验收与限制

- Windows 原生快捷键、通知横幅/点击、完整设置流程和真实模型/记忆服务，以及 macOS 原生行为仍需逐项验收；本 RC 不代表正式版已发布。签名、公证及安装包验收限制沿用仓库发布流程。
- 真实子 Agent 路由、双 Profile 提供商同步及目标补充认证待验收；上游没有原子条件创建或跨接口事务保证。YAML 提交前检查也不构成服务端原子并发控制。
- 检查点恢复、清理和删除不在本批范围；锁定上游非默认 Profile 的 rollback.list、单次 MoA 后下一轮普通消息恢复原模型端点仍有已知问题。
- 快捷输入待决请求不自动跨主窗口异常重载恢复。WorkBuddy 异常中断后不完整 Profile 的自动恢复仍未实现。
- 统一设置全局搜索、语音能力、远程连接、Cloud 登录和 SSH 托管更新等迁移项尚未完成，不能把完整 YAML 可编辑对应字段视为能力已接入。

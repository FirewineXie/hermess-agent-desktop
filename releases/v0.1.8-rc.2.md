# Hermess Agent Desktop v0.1.8-rc.2

## 新增功能

- 包含 rc.1 的 WorkBuddy 专家包导入、Profile 配置与桌面通知功能。
- 统一设置新增安全与高级配置页面，支持审批、隐私、检查点、运行参数、工具、终端和完整 YAML 编辑。
- 新增模型与 Profile 委派路由，以及自定义模型提供商同步。
- 新增设备保持唤醒、Windows F12 和全局快捷输入；通知扩展到后台任务、其他会话、额度和插件消息。
- 支持粘贴聊天截图并预览附件缩略图；侧栏显示会话运行、待处理、完成和失败状态。

## 修复问题

- 修复新建 Profile 继承原 Profile 主模型和自定义提供商的问题。
- 修复会话思考预览结束时，侧栏过早显示运行完成的问题。
- 修复设置保存时已删除配置项仍被保留、YAML 外部修改未检查等问题。

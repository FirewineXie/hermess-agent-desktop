# Hermess Agent Desktop v0.1.8-rc.3

## 新增功能

- 设置中新增独立的软件更新页和开发者诊断页；聊天主页面连续点击空白区域五次可显示诊断入口。
- 聊天消息支持预览本地 HTML 画廊中内嵌的图片。
- 客户端可记录窗口异常、未处理的 Promise 错误、Rust panic 和自有后端异常退出，供开发者诊断查看。

## 修复问题

- 软件更新下载进度在切换页面后可继续查看；校验完成后可打开系统安装包。
- Windows 安装器升级已有同产品安装时直接覆盖，同版本重装和降级分别要求确认。

# Hermess Agent Desktop v0.1.9-rc.1

## 新增功能

- 渠道页支持配置、启停和测试更多消息渠道；Telegram、钉钉、企微、QQ Bot 和 WhatsApp 提供扫码接入入口。
- 飞书和微信扫码时可选择私聊直接放行或首次消息需审批；已配置渠道可在卡片下方批准配对码，无需重新扫码。
- 压缩模型可从当前 Profile 已配置的厂商中选择，并设置推理强度与超时。
- 桌面界面语言可同步到本产品服务的 Profile；明确自行设置过语言的 Profile 保持原值。

## 修复问题

- 修复外部渠道会话在侧栏更新不及时，以及已打开会话的完成状态未及时清除的问题。
- 修复渠道扫码弹窗中私聊准入选项无法点击和中文提示显示翻译键的问题。
- 修正配对码找不到时的提示，明确当前 Profile 与配对码可能已使用或过期的区别。

# Hermess Agent Desktop v0.1.10-rc.3

## 新增功能

- 聊天中支持图片放大、音视频播放，以及文件预览、另存为和本地定位；媒体路径按所属会话和本地或远程 Gateway 解析。
- 已保存的远程 Gateway 配置支持确认后删除，同时清除本机保存的对应凭据。

## 修复问题

- Gateway 重启或连接异常后自动尝试恢复；持续无法连接时由客户端清理自有进程并重新启动，保留会话历史和草稿，失败时可在当前页面重试。
- 连接中断时更新页面连接状态，避免仍显示“已连接”；主动停止或切换 Gateway 会取消恢复。
- 顶部 Gateway 菜单支持点击外部收起，按 Esc 关闭并返回触发按钮。
- 插件市场按 Profile 显示安装状态，安装前核对 Gateway 当前目录与固定提交，避免 OpenViking 等插件重复安装或因旧目录无法安装。
- OpenViking 等专属记忆提供方显示当前配置状态，并引导到记忆提供方设置，避免普通插件开关造成启用状态误判。
- 修复设备偏好页重复标题和主题选项排版，统一设置页按钮、导航及聊天界面的深色主题样式。
- 补齐会话管理、安全配置、运行时控制、技能整理器、备份、主机状态和首次使用引导的深色样式。
- 修复新聊天因会话创建参数与当前 Gateway 不匹配而发送失败的问题。
- 修复凭据池页面操作按钮文字不可见的问题。

# Hermess Agent Desktop v0.1.9-rc.3

## 新增功能

- 以产品自有 React 页面接入锁定 Hermes Dashboard 的会话、文件、统计、模型、日志、定时任务、扩展、配对、渠道、Webhooks、Profile、配置、密钥、文档和运行时管理能力。
- 持续任务支持多 Profile 看板、父子任务、自动拆解与推进、Dispatcher 分派、运行诊断、人工与自动审核、退回返修及成果汇总。
- 扩展中心提供技能、插件和 MCP 市场；按 Profile 管理本地扩展与通用 MCP 配置，并接入 Dashboard 插件页面和公开 SDK。
- 聊天支持图片和文件、审批与澄清、停止与继续、会话恢复、产物预览、子代理面板、多聊天标签、独立聊天窗口及全局命令面板。
- 新增首次启动引导，以及单个 Bot 的固定聊天和支持 2–6 个 Bot 协作的群聊。
- 设置与运行时页面提供按 Profile 的模型、OAuth、凭据池、记忆提供方、完整配置、环境密钥及产品数据备份管理。

## 修复问题

- 修复持续任务审核人可以与执行者相同，导致退回返修缺少执行者来源的问题。
- 修复持续任务详情评论不易发现、历史和诊断内容堆叠的问题；看板默认只展示有任务的状态，并按需展开次要设置和历史记录。
- 修复 Bot 页面浅色主题下的深色卡片与表单样式不一致问题。
- 修复 Dashboard 插件隐藏页、根路由覆盖、内建路由冲突、后注册覆盖顺序和多语言 SDK 与锁定宿主不一致的问题。
- 修复多 Profile 管理下模型、配置、文件、会话、定时任务和扩展操作可能落入错误 Profile 的边界问题。

# Hermess Agent Desktop v0.1.8

## 新增功能

- 支持导入 WorkBuddy 团队专家包，并扩展 Profile 的模型、MoA、记忆、上下文、插件和工具集管理。
- 统一设置新增安全、高级配置、软件更新与开发者诊断页面。
- 增加桌面通知、设备保持唤醒、Windows F12 和全局快捷输入；聊天支持粘贴截图与预览附件。
- 聊天新增会话分支、消息撤销、运行中插入消息、待处理队列、旁路提问和后台任务入口。
- 增加 `/reload-mcp`、`/reload-skills` 与产品自有浏览器命令；学习时间线支持查看、编辑和删除当前 Profile 的记录。

## 修复问题

- 修复新建会话失败、命名 Profile 的澄清回答卡住，以及恢复会话后过早显示完成的问题。
- 修复 Windows 路径兼容与 PowerShell 工具在桌面会话中的可用性问题。
- 修复模型与设置项保存、Profile 隔离，以及软件更新下载进度在页面切换后的显示问题。
- Windows 安装器升级已有同产品安装时直接覆盖，同版本重装和降级分别要求确认。

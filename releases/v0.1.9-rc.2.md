# Hermess Agent Desktop v0.1.9-rc.2

## 新增功能

- 以产品自有 React 页面完整接入锁定 Hermes Dashboard 的会话、文件、统计、模型、日志、定时任务、扩展、配对、渠道、Webhooks、Profile、配置、密钥、文档和运行时管理能力。
- 持续任务升级为完整多 Profile 看板，支持状态折叠树、父子任务、自动拆解与推进、Dispatcher 分派、三种工作区、运行诊断、人工与自动审核、退回返修及成果汇总。
- 扩展中心提供技能、插件和 MCP 市场；本地技能、插件、工具集和通用 MCP 配置统一归入 Profile 管理，并接入 Dashboard 插件页面、插槽、路由覆盖及公开 SDK。
- 设置页新增按 Profile 的模型与 OAuth、凭据池、记忆提供方、完整配置和环境密钥管理；运行时与存储统一管理全局 Gateway、主机状态及覆盖全部 Profile 的完整备份。
- 聊天页补充图片与文件、剪贴板图片、断线续传、审批与澄清、停止与继续、会话命令、回滚差异预览和安全恢复。

## 修复问题

- 修复持续任务允许执行 Profile 审核自身任务，导致退回返修缺少执行者来源的问题。
- 修复 Dashboard 插件隐藏页、根路由覆盖、内建路由冲突、后注册覆盖顺序和多语言 SDK 与锁定宿主不一致的问题。
- 修复多 Profile 管理下模型、配置、文件、会话、定时任务和扩展操作可能落入错误 Profile 的边界问题。
- 优化看板、渠道接入、Profile 管理、扩展市场和运行时页面的布局、层级、折叠关系、空态、错误态与操作反馈。

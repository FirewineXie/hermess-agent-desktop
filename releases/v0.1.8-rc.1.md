# Hermess Agent Desktop v0.1.8-rc.1

这是 v0.1.8 的首个候选版本。发布工作流将从此 tag 分别构建 Windows x64 与 macOS Apple Silicon 安装包；实际可下载附件以构建结果为准。

## 本版本内容

- 新增 WorkBuddy 团队专家包导入：选择本地目录、预览主理人和成员、Skill 与 SOUL，确认后创建独立 Profile；保存角色原文及 Skill 的脚本、模板和素材。成员不会被误登记为已注册的子 Agent，来源包没有声明的 MCP 不会被推断安装。
- 扩展 Profile 设置中的模型提供商、MoA、记忆与上下文配置，以及外部记忆提供方入口；修复默认提供商删除、MoA 空活动方案和相关输入默认值。
- 增加桌面原生通知与补充信息、审批卡的交互处理，并修复会话恢复后等待时间线的结束判定。
- 顶栏仅在发现新版本时显示更新入口；修订 Windows PowerShell Tool 的模型可见路由说明。

## 验证与限制

- Windows 本地通过前端生产构建、共享契约和架构检查、Rust 格式与编译检查，以及全量 Rust 单元测试（82 项通过、5 项按环境跳过）。两个 WorkBuddy 样本的解析、逐文件复制比对和 Hermes Skill 索引扫描分别核对出 9 个与 1 个 Skill。锁定 Hermes 的独立 Profile 创建、SOUL 写入及 Skill 目录初始化冒烟通过；用户反馈本地桌面测试没有发现问题，但未提供两个包的逐项原生操作记录。
- WorkBuddy 导入在异常退出后自动恢复不完整 Profile、Gateway 中实际调用 Skill、图像/视频模型、微信账号与外部 API、Python 脚本真实运行、macOS 原生导入及安装包仍需验收。其他 v0.1.8 功能的逐项验收范围见 `ROADMAP.md`；本 RC 不代表正式版已发布。

构建输入：Hermes 官方基线 `v0.22.5`（`bf0203a794a07aac3ff764972ab9087baa4e4f4e`），产品锁定的 `hermess-desktop` fork 提交 `882037eb8745b505db438217513c4c94f95c93c1`。本候选版未修改该 fork。

# Hermess Agent Desktop v0.1.8-rc.1

## 新增功能

- 支持导入 WorkBuddy 团队专家包，预览角色、Skill 和 SOUL，并创建独立 Profile。
- 扩展 Profile 的模型提供商、MoA、记忆与上下文设置，增加外部记忆提供方入口。
- 增加桌面通知及补充信息、审批卡交互；顶栏仅在发现新版本时显示更新入口。

## 修复问题

- 修复删除默认模型提供商、MoA 活动方案为空及相关输入默认值的问题。
- 修复恢复会话后等待时间线过早结束的问题。

# v0.1.5-rc.1 候选版本

这是 `v0.1.5` 的首个候选版本。它汇集了前端、桌面客户端与接口契约的拆分，以及自有 Hermes 运行时的连接边界调整。候选版本仍需原生窗口、真实模型与跨平台安装验收。

## 本版本内容

- 前端按页面、功能控制器和组件组织；桌面客户端按运行时、聊天、模型、配置、工具、诊断与存储职责拆分，跨项目接口由共享契约约束。
- 聊天支持多会话切换、思考内容与工具过程展示、Markdown 回复、审批和澄清、附件与会话恢复；Agent 设置、人格与记忆文件、扩展目录等页面继续完善。
- 新增「关于」页面，离线展示产品与上游许可证、版本和工具来源说明；软件更新页面保存正式版或 RC 渠道偏好。可信发行源尚未确定，在线检查及安装按钮未开放。
- 新增飞书和微信扫码渠道接入；桌面隐藏到系统托盘，聊天和消息渠道由一个自有 Hermes 网关进程承载。
- Windows 开发环境准备脚本显式安装 `messaging` 和 `feishu` 可选依赖；使用新环境后，微信渠道不再报告 `adapter_unavailable`。真实微信消息收发仍待验收。
- 固定官方 Hermes Agent `v0.22.5` 基线 `bf0203a794a07aac3ff764972ab9087baa4e4f4e`，产品构建锁定维护 fork 提交 `882037eb8745b505db438217513c4c94f95c93c1`。桌面私有 API 适配已纳入 fork 提交。
- 桌面私有模式只允许网关监听 `127.0.0.1`，根路径不再向浏览器公布会话令牌，带浏览器 `Origin` 的 WebSocket 握手被拒绝。桌面启动时会核验这两个边界。

## 验证范围与限制

- Windows x64 本地已通过前端与桌面 UI 构建、共享契约与架构检查、Rust 格式检查和单元测试（30 项通过，1 项需离线归档而跳过）。锁定 fork 的 core payload 构建及校验通过；打包网关的私有票据 WebSocket ping 与飞书、微信渠道状态接口通过。
- 飞书与微信的线上二维码启动接口返回有效数据；手机扫码、真实收发、桌面原生窗口托盘操作和候选安装包尚未验收，macOS/Linux 实机也未验收。GitHub Release 的安装包是否生成，以此标签的发布工作流结果为准。
- 私有模式的 HTTP 接口使用随机令牌，聊天 WebSocket 使用网关私有控制端签发的票据。对同一用户下恶意本机进程的完整防护不在本轮验收范围内。

完整进度与剩余问题见 `ROADMAP.md` 和 `docs/capability-matrix.md`。

# Hermess Agent Desktop v0.1.8-rc.4

## 新增功能

- 扩展中心新增 Hermes 插件目录和插件管理，专家页面可查看各 Profile 的插件。
- 专家管理支持删除非默认 Profile，并可用中文修改显示名称。
- 新增桌面使用向导；完整 YAML 配置编辑支持格式检查和格式化。
- Windows PowerShell Tool 可用于各 Profile，常用文本读写默认使用 UTF-8。

## 修复问题

- 修复命名 Profile 概览读取时提示“当前状态已变化”的问题。
- 修复新建会话输入 `@` 或 `/` 时不显示技能与命令候选的问题。
- 正式构建不再显示“发送测试通知”按钮；PowerShell Tool 介绍仅在 Windows 显示。

# Hermess Agent Desktop v0.1.12-rc.1

## 新增功能

- Webhooks 支持命名 Profile；订阅按 Profile 隔离，并生成对应 Profile 的投递地址。
- macOS 编程输入支持粘贴从 Finder 复制的文件或文件夹路径。

## 修复问题

- 修复宽窗口下聊天正文、助手消息和输入区仍然过窄的问题。
- 修复命名 Profile 的 Webhooks 页面读取共享监听器状态时返回 403 的问题。
- 将集成的 Chrome for Testing 升级到 157.0.8103.78，并为 Linux ARM64 改用官方原生构建。

- 基于 Hermes Agent v0.23.0；fork hermess-desktop（de89d9331122e67f16f01ce5784cd9721a3aa131）。

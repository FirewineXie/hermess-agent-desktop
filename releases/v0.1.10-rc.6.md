# Hermess Agent Desktop v0.1.10-rc.6

## 新增功能

- 存储设置支持选择新位置、保存下次启动生效及取消更改；启用失败时可重试或重新选择，原位置数据保留。
- 编程模式可直接使用产品已安装的 Python、Node、npm 和 uv 工具。

## 修复问题

- 本地 Gateway 运行时提示先停止，避免在运行中更改存储位置。
- 软件更新安装包保存到产品专用系统临时目录，避免占用下载目录。

- 基于 Hermes Agent v0.22.5；fork hermess-desktop（882037eb8745b505db438217513c4c94f95c93c1）。

# Hermess Agent Desktop v0.1.11-rc.2

## 新增功能

- Profile 插件管理页显示 Dashboard 插件声明的页面与插槽、实际注册结果及加载失败原因。独立插件页显示插件名称并可返回原页面。
- 内置 `hermess-plugin-development` Skill，可在聊天中按需求开发 Dashboard 插件，随客户端部署到本地 Profile。
- 「设置 → 模型 → 辅助模型」集中管理内置辅助模型和默认委派的子 Agent 模型。

## 修复问题

- 修复从 Git 安装插件后误报未启用的问题。安装、启停和重新扫描后会刷新 Dashboard 界面。
- 修复回退模型配置仅因字段顺序不同而被误报回读失败的问题。
- 移除侧栏「更多」里重复的「工具与能力」，可在「设置 → 桌面」打开。

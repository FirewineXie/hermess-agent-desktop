# Hermess Agent Desktop v0.1.12-rc.5

## 新增功能

- 重整桌面工作区视觉体系，统一聊天、编程、工作区、任务、扩展中心、设置与 Profile 页面布局，并提供更舒适的暖白浅色和低亮度深色主题。
- 全局功能栏和页面操作统一使用同一套线性图标，收紧导航尺寸、间距和控件层级。

## 修复问题

- 修复深色主题下部分卡片背景过亮、侧栏图标悬停提示文字对比度不足的问题。
- 修复多处页面沿用旧配色、字符图标和不一致交互状态的问题。

# Hermess Agent Desktop v0.1.7-rc.1

## 新增功能

- Windows 运行时安装到程序目录的固定路径；覆盖安装先准备并校验新运行时，成功启动后清理旧目录。
- 桌面端通过自有 Gateway 的私有控制端获取进程信息与交互票据。
- 改进模型提供商、默认模型和 Profile 配置的查看与编辑。

## 修复问题

- 修复 Windows 覆盖安装时，安装器遗留文件句柄导致误报旧运行时被占用的问题；临时占用可重试，失败后可复用完整暂存目录。
- 修复 Windows 长路径下的 Gateway 控制管道定位问题。

## Hermes fork 版本

- 基于 Hermes Agent v0.22.5；fork hermess-desktop（882037eb8745b505db438217513c4c94f95c93c1）。

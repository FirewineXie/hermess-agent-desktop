# Hermess Agent Desktop v0.1.7-rc.1

这是 v0.1.7 的首个候选版本。发布工作流将分别构建 Windows x64 和 macOS Apple Silicon 安装包；实际可下载附件以本 Release 的构建结果为准。

## 本版本内容

- Windows 运行时安装到程序目录的固定 `runtime/payload` 路径。覆盖安装先准备新运行时，再切换目录；旧目录在新版 Gateway 成功启动后由客户端后台清理。用户 Profile 和依赖环境继续保留在产品数据目录。
- 修复 Windows 安装器读取运行时摘要后可能遗留自身文件句柄、导致覆盖安装误报“旧运行时被占用”的问题。临时占用时安装器可重试；失败后再次运行可复用完整暂存目录。
- 桌面端直接连接自有 Gateway 的私有控制端完成进程发现与交互票据获取；修复 Windows 长路径下的控制管道定位。发行版辅助 Python 改用随包基础解释器，并在打包前验证搬迁后的导入能力。
- 改进模型提供商配置、默认模型与 Profile 页面中的配置查看和编辑体验。

## 验证与限制

- Windows 本地通过前端构建、架构与契约检查、Rust 格式检查及单元测试（71 项通过、5 项按条件忽略）。离线 Windows 安装包构建和隔离安装器测试通过；在现有安装目录完成静默覆盖安装，固定运行时路径与暂存目录切换核对通过。
- 安装包的交互界面、新版 Gateway 启动后的后台清理、真实模型调用与 macOS 原生安装仍需验收。候选版不代表正式版已发布；CI 构建成功也不等于上述实机验收。

完整进度与剩余问题见 `ROADMAP.md`。

# Hermess Agent Desktop v0.1.11-rc.3

## 新增功能

- 独立插件页支持直接切换 Profile，显示对应 Profile 的插件；未安装或未启用时提供安装、管理入口。

## 修复问题

- 优化聊天中的审批、建议和后台任务展示，使用浅色细边界，长问题和补充输入按需展开。
- 修复子代理任务面板与详情无法关闭的问题，支持再次点击收起及 Esc 关闭。
- 子任务完成通知默认折叠到聊天中，保留助手总结，内部记录可按需查看；重新打开历史时保持相同展示。
- 修复空子任务面板随轮询反复出现导致聊天页面抖动的问题。
- 修复待发送图片附件无法移除的问题。

## Hermes fork 版本

- 基于 Hermes Agent v0.23.0；fork hermess-desktop（222b3748470c369050078ff3864100deb609918e）。

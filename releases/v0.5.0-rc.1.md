# v0.5.0-rc.1 候选版本

这是 `v0.5.0` 的首个候选版本。它汇集了前端、桌面客户端与接口契约的拆分，以及自有 Hermes 运行时的连接边界调整。候选版本仍需原生窗口、真实模型与跨平台安装验收。

## 本版本内容

- 前端按页面、功能控制器和组件组织；桌面客户端按运行时、聊天、模型、配置、工具、诊断与存储职责拆分，跨项目接口由共享契约约束。
- 聊天支持多会话切换、思考内容与工具过程展示、Markdown 回复、审批和澄清、附件与会话恢复；Agent 设置、人格与记忆文件、扩展目录等页面继续完善。
- 固定上游 Hermes Agent `v0.22.5`，提交 `bf0203a794a07aac3ff764972ab9087baa4e4f4e`，构建来源为产品维护的 `FirewineXie/hermes-agent` fork。产品适配文件以 `hermess_` 为前缀，由仓库跟踪并在检出后应用。
- 桌面私有模式只允许网关监听 `127.0.0.1`，根路径不再向浏览器公布会话令牌，带浏览器 `Origin` 的 WebSocket 握手被拒绝。桌面启动时会核验这两个边界。

## 验证范围与限制

- Windows x64 本地已通过前端类型检查、共享契约与架构检查、Rust 格式检查和单元测试（28 项通过，1 项需离线归档而跳过）。上游检出及适配补丁校验、固定上游假模型 Gateway 冒烟此前通过。
- 此候选版本尚未完成新适配后 payload 和安装包的本地构建，也未完成原生窗口、真实模型及 macOS/Linux 实机验收。GitHub Release 的安装包是否生成，以此标签的发布工作流结果为准。
- 私有模式的 WebSocket 仍使用本机 `ws://` 和进程持有的令牌；它不提供对同一用户下恶意本机进程的身份认证。

完整进度与剩余问题见 `ROADMAP.md` 和 `docs/capability-matrix.md`。

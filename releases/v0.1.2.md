# v0.1.2 跨平台安装包修订

本版修正 `v0.1.1` 的 Linux AppImage 打包失败：为 Tauri 明确配置正方形 PNG 图标，同时保留 Windows ICO 和 macOS ICNS。先前的版本标签保留为构建记录，不移动或复用。

## 本版本内容

- 固定上游 Hermes Agent 提交 `5894e750c3dba980d43b25aa29e3958149ba2c61`，产品代码与上游源码分离。
- 中文桌面界面支持模型设置、会话创建与历史恢复、流式回复、停止、审批、澄清、文件和图片附件。
- 运行时归档随安装包交付，首次启动解包到所选主要存储位置，并核对摘要和上游版本。
- Windows x64 构建 NSIS；macOS Intel 和 Apple Silicon 构建 DMG；Linux x64 构建 AppImage 和 deb。

## 验证范围与限制

- Windows x64 已通过固定核心包的假模型协议冒烟、离线归档解包，以及同机 NSIS 静默安装和卸载。
- GitHub Actions 分别编译四个目标，全部成功才生成包含五个安装包和 SHA256SUMS 的草稿 Release。构建状态以本标签工作流为准。
- macOS 与 Linux 的原生窗口、安装、真实模型和工具链仍需在对应系统验收。
- 安装包未配置正式代码签名与 Apple 公证；此版本尚未达到正式公开发布门槛。
- 本仓库自行编写的代码采用 PolyForm Noncommercial 1.0.0；上游 Hermes Agent 子模块保留其 MIT 许可。

完整实施状态见 `docs/I0-implementation.md` 和 `docs/capability-matrix.md`。
